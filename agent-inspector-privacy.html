Agent Inspector — Privacy policy

Agent Inspector is an unofficial community browser extension. It is not affiliated with or endorsed by Microsoft.

What it reads

  • The URL of the active Copilot Studio tab (environment and agent IDs).
  • Bot Framework activities that the Copilot Studio test chat already exchanges in your browser (messages, events, traces), so they can be shown in the side panel.
  • Agent definition data (agent, topics, tools, flows, connection references, solutions, evaluation records) from the Dataverse environment you are working in, using read-only requests made as you.
  • If Dynamics 365 Contact Center (Omnichannel) is installed: workstreams, queues and their members, context variables, the agent's application user and related solutions. For the optional access check: the name, email, roles, team roles and queues of a person you search for, and their access rights to the agent. All read-only, shown only in your side panel and never stored.

How it authenticates

  • It reuses the access token that Copilot Studio itself sends to your Dataverse environment, or your existing browser session with that environment.
  • Tokens are kept only in the browser's in-memory session storage and are discarded when the browser closes. They are never written to disk.
  • You can turn token reuse off in Settings → Sign-in. Stored tokens are then deleted immediately and only your browser session is used.
  • Session cookies, passwords and refresh tokens are never read.

What it stores

  • In memory (cleared when the browser closes): captured activities for open tabs, short-lived tokens.
  • On disk (browser extension storage): the Dataverse URL detected for each environment and your settings.

What it sends

  • Nothing to the developer or any third party. The only network requests go to Microsoft endpoints you are already using: your Dataverse environment and the Power Platform admin API (to look up the environment's Dataverse URL).
  • No analytics, no tracking, no remote code.

What it changes

  • Nothing. The extension never creates, updates or deletes data in Copilot Studio or Dataverse, and never changes routing, queues, users or roles.
